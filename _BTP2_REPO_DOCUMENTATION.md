## Project Overview

This repository contains the full pipeline for **BTP-2 (Bachelor Thesis Project, Part 2)** — a research project studying **emotion alignment between Mind (self-report) and Body (physiology)** when people watch movie clips.

The core hypothesis framework tests three relationships per clip:
- **P** = Perceived (what the viewer thought the clip showed emotionally)
- **E** = Expressed (what the clip's audio/video **actually** expressed, as detected by AI models)
- **I** = Induced (what emotion the viewer **actually felt**, either self-reported or inferred from Fitbit/heart-rate data via an LLM)

Clips are sorted into 5 buckets:
- **H1 (Match):** P = E = I — total agreement
- **H2 (Feel):** P = I ≠ E — person felt what they expected, not what was expressed
- **H3 (Drift):** P = E ≠ I — person understood the clip but felt differently
- **H4 (Cognitive Dissonance):** E = I ≠ P — body and clip agreed, but person misread it
- **H5 (Chaos):** None of the above match

### Core Python Scripts

#### Phase 1: Data Preparation
| Script | Purpose |
|---|---|
| `BTP_Phase1/main.py` | **Entry point for Phase 1.** Reads `clip_responses_export.xlsx`, filters for 6 participants, and pivots data into `valence_btp2.csv` and `arousal_btp2.csv` — the per-clip, per-participant wide-format CSVs needed for all downstream analysis. |
| `calculate_final_expressed.py` | Determines the single best **expressed emotion** per clip. Applies 3-case logic: (1) ignore if neither audio nor video is useful; (2) use the one that is useful; (3) if both are useful, pick the one closest to perceived emotion. Outputs: `final_expressed_valence.csv`, `final_expressed_arousal.csv`, `ignored_clips_list.csv`. |
| `generate_expressed_emotions_both_sources.py` | Generates **both** audio and video expressed emotion files separately (rescaling 0–1 → 1–5). Outputs: `final_expressed_{dim}_AUDIO.csv`, `final_expressed_{dim}_VIDEO.csv`, and `video_vs_audio_comparison.csv`. |

#### Phase 2: Statistical Analysis
| Script | Purpose |
|---|---|
| `BTP_Phase2/run_phase2_analysis.py` | **Phase 2 analysis.** Computes per-participant Cognitive Alignment, Emotional Resonance, and Average Drift. Also ranks all clips by drift magnitude. Outputs: `participant_analysis_{dim}.csv`, `clip_drift_ranking_{dim}.csv`, `BTP2_Phase2_Final_Report.txt`. |
| `final_stats.py` | **Comprehensive Q1–Q5 statistical engine.** Computes: Q1 (P vs E agreement + Fleiss' Kappa), Q2 (self-reported I match vs expectation), Q3 (physiological I match vs expectation using chi-square), Q4 (correlation between rep vs inferred I), Q5 (best-case validation). Saves report to `BTP_Final_Dynamic_Report.txt`. |
| `permutation_analysis.py` | Detailed case-by-case analysis of all P/E/I permutations (p=e=i, p=i≠e with sub-cases, p=e≠i with sub-cases, none). Runs for valence and arousal, both self-reported and physiological. |
| `analyze_pe_i_matches.py` | Finds clips satisfying \|P−E\| ≤ 1 (PE match) and then \|P−I\| ≤ 1 on top (PEI match). Saves `pe_match_{dim}.csv` and `pei_match_{dim}.csv`. |
| `analyze_pe_inferred_matches.py` | Same as above but uses LLM-inferred emotion as I (Body data version). |

#### Hypothesis Engines
| Script | Purpose |
|---|---|
| `generate_btp_hyptohesis_FINAL.py` | **V4 hypothesis generator.** Runs the 4-bucket (Match/Feel/Drift/NoMatch) analysis across all thresholds, both SELF (P/E/I_self) and BODY (P/E/I_body = LLM inferred), all modalities (VIDEO/AUDIO/INTERSECT). Outputs: `MASTER_BTP_HYPOTHESIS_V4_FINAL.csv`. |
| `generate_btp_hyptohesis_V5_FINAL.py` | **V5 (5-bucket) hypothesis generator.** Adds a 5th bucket H4 (Cognitive Dissonance: E=I≠P) and a "Universal Truth" sub-table (clips where I=B across both). Calculates Mind-Body agreement rates. Outputs: `MASTER_BTP_HYPOTHESIS_V5_5BUCKET.csv`, `MIND_BODY_AGREEMENT_TABLE.csv`. |
| `run_all_thresholds.py` | Iterates over thresholds [0.25, 0.5, 0.75, 1.0] and modalities [AUDIO, VIDEO] for the threshold analysis, printing SELF and BODY tables with Audio ∩ Video overlap. Outputs: `MASTER_THRESHOLD_RESULTS_AV.csv`. |
| `run_threshold_analysis_BOTHSOURCES.py` | Full P-I-E threshold analysis using both VIDEO and AUDIO expressed emotions. Categorizes clips as P=I=E, P=E≠I, P≠E=I, P≠I≠E. Outputs: `THRESHOLD_PIE_RESULTS_BOTH_SOURCES.csv`, `THRESHOLD_PIE_SUMMARY_BOTH_SOURCES.csv`, `COMPARISON_PIE_tau_{t}.csv`. |
